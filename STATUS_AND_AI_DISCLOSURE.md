# Status, AI use, and authorship boundary

## Public status

This package is an **AI-assisted open verification dossier**. It is:

- not peer reviewed;
- not a journal submission or preprint submission;
- not deposited on Zenodo and has no DOI;
- not an established theorem;
- not a solution of the generalized Fermat equation of signature `(3,5,7)`;
- not a proof or counterexample to the Beal conjecture;
- not a prize submission.

## Claim boundary

The exact files and scripts can support statements of the form:

> "The bundled program reports this output when run against the stated input and hash."

They do not, without expert review and source validation, support statements of the form:

> "This theorem has been proved" or "the Beal conjecture has been solved."

Every mathematical conclusion must be rechecked from definitions, hypotheses, sources, and code by qualified independent reviewers.

## Why this is on GitHub only

Current journal, arXiv, and research-repository policies require human accountability and genuine human-conducted research. The uploader's disclosed inability to independently defend the derivations prevents an honest scholarly submission at this stage. GitHub is used only to expose the artifact for criticism and verification without claiming peer review, academic acceptance, or a DOI.
